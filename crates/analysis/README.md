# Bounded Analysis

`atlas-analysis` accepts producer-independent facts, never executes an analyzed
repository, and returns versioned interpretations. The server must authorize and
pin every selected snapshot/context and imported observation before calling it.

## Graphs

`analyze_graph` computes iterative petgraph Kosaraju SCCs and a condensation graph
over selected direct calls. Recursive SCCs include self-loops. It reports distinct
fan-in/fan-out separately from call-site counts, source metrics already present in
the frontend facts, declared `pub` visibility, and empirical metric distributions.
Medians use the lower middle value; p95 uses the nearest-rank convention.

`find_path` uses petgraph BFS to find one shortest outgoing static path or a bounded
reachable set. Stable IDs determine node, edge and tie-break order. It never
enumerates all execution paths or precomputes all-pairs reachability. A found path
is not proof of runtime feasibility. `not_found_in_selection` is available only
for a fully traversed, complete selected graph with the target present; incomplete
facts, unknown boundaries or budget limits return `unknown`. With no target, a
complete selected traversal returns `reachability_complete`.

Graph results apply only to the supplied selection. A component can grow when
external nodes are included; fan counts can increase. Resolved calls leaving the
selection and unresolved call sites remain explicit frontiers. Source line counts
are not noncomment LOC. Source branches are not compiler CFG cyclomatic complexity.
Visibility does not resolve reexports or externally reachable APIs. No universal
quality score is calculated.

Defaults: 200 nodes, 500 call sites, 200 BFS visits, depth 8, 2 MiB output. Hard
limits: 10,000 input nodes, 50,000 input edges, 16 MiB serialized input, 10,000 BFS
visits, depth 64, 2 MiB output. Oversized input/output returns `BudgetExhausted`
without returning a false negative. Cancellation/deadlines are checked while
preparing and traversing facts. The iterative O(V+E) petgraph SCC pass is bounded
by hard caps and checked immediately before/after; it is not interruptible inside
the library call. The integration scheduler remains responsible for hard process
resource isolation and cancellation of input collection.

## Trace Windows

`compare_trace_windows` operates on one explicitly selected stream from each
imported bundle. It selects the first common correlation ID that is unique in
both bounded windows, then compares the event-kind/correlation-ID prefix in
per-stream sequence order. Repeated IDs are ambiguous, not guessed. At most 2,000
events and 2,000 anchors per selected window are permitted. Input bundles retain
the import limits of 64 streams and 10,000 events; comparison input is capped at
16 MiB and output at 2 MiB.

The first observed divergence is labeled with its alignment rule, never called a
root cause. Timestamps and sequences remain decimal strings; elapsed intervals
use each stream's own clock and unit, with no cross-clock subtraction or imposed
total order. Nonmonotonic timestamps suppress interval calculation. Event-loss
counts are retained without 64-bit aggregate overflow. Bundles keep distinct
artifact identities; equality of event kinds is not payload equality, behavioral
equivalence, run-input compatibility or permission to reuse a historical test.
Unaligned prefixes and unselected suffixes remain explicit limitations.

## Independent Oracle

`tests/fixtures/semantic_oracle.json` is a hand-authored site-by-site contract,
not generated from analyzer output. Its Rust fixture has same-named functions
with distinct values, an alias, an inherent method, recursion and an indirect
function-pointer boundary. A pinned-rustc compile/runtime control validates only
this trusted fixture. Tests deliberately change the alias target, delete a call
site and falsely resolve a function pointer; the independent contract rejects
each mutation. Compiler/runtime acceptance and this small oracle do not prove
complete call-graph coverage or qualify an entire corpus.

Run `cargo test -p atlas-analysis` and `cargo clippy -p atlas-analysis --all-targets
-- -D warnings`. Public TypeScript contracts are generated by
`atlas_analysis::typescript()` for integration into the canonical generator.
