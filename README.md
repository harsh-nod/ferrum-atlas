# Ferrum Atlas

Source-linked Rust code maps, durable snapshots, and evidence-aware change review.

Ferrum Atlas is being implemented from the included [design specification](rust_analyzer_and_visualizer.md). The initial delivery is a local analyzer and browser viewer. Compiler MIR, hosted multi-user operation, and organization-scale qualification are later milestones, not current capabilities.

## Development

Rust is pinned in `rust-toolchain.toml`. The integration branch stays on `main`.
Implementation notes and acceptance evidence live under `docs/`.
